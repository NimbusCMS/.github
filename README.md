# NimbusCMS

Default community health files for every repository in the
[NimbusCMS](https://github.com/NimbusCMS) organization.

A repository that does not define its own `CONTRIBUTING.md`, `SECURITY.md`,
issue templates and so on inherits the ones here.

## What lives in this organization

Only **officially maintained** Nimbus software:

| Repository | Purpose |
|------------|---------|
| [`nimbus`](https://github.com/NimbusCMS/nimbus) | the CMS core |
| [`plugin-*`](https://github.com/orgs/NimbusCMS/repositories?q=topic:nimbuscms-plugin) | official plugins |
| [`theme-*`](https://github.com/orgs/NimbusCMS/repositories?q=topic:nimbuscms-theme) | official themes |

Community plugins and themes stay in their authors' own accounts. They can be
listed in the future Nimbus directory without being transferred here — being
listed does not mean being maintained by Nimbus. A community project moves into
this organization only when Nimbus deliberately takes on ongoing maintenance,
and only with the author's agreement.
